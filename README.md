# Real Estate Acquisition Financial Model

## Overview

This project consists of a dynamic Excel financial model used to evaluate commercial real estate acquisition opportunities. The model forecasts property cash flows, financing, operating performance, and investment returns under multiple scenarios.

## Technologies

- Microsoft Excel

## Skills Demonstrated

- Financial modeling
- Discounted cash flow (DCF) analysis
- Investment analysis
- Sensitivity analysis
- Scenario modeling

## Financial Metrics

- Net Present Value (NPV)
- Internal Rate of Return (IRR)
- Equity Multiple
- Cash-on-Cash Return

## Key Features

- Dynamic assumptions
- Financing schedules
- Cash flow forecasting
- Sensitivity analysis
